## Overview

This repository demonstrates a complete workflow for analyzing **Spatial Transcriptomics data from mouse brain tissue** using **Seurat** and **CellChat**.

### Features

- 🧬 Spatial transcriptomics analysis
- 📊 Quality control and normalization
- 🧠 Mouse brain clustering and annotation
- 📍 Spatial visualization
- 🔗 Cell-cell communication analysis with CellChat
- 📈 Signaling pathway exploration
- 🎨 Publication-ready figures
